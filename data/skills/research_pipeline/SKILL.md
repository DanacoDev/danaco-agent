---
name: research_pipeline
description: Appends a research log to its own wiki file, wiki/research.md by default. Never writes the project description. args query, notes, and optional name.
version: 1.0.0
---

args query, notes, and optional name. query is what was looked up. notes are the findings. name is a different wiki markdown file when the topic should not go in wiki/research.md. The pipeline never writes the project description.
