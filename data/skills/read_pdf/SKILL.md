---
name: read_pdf
description: Reads the text of a PDF, including a scan. args path, optional question.
version: 1.0.0
---

args path, optional question. Reads the text of a PDF. A scan or a page with no text is read from the page image, including amounts and totals. Pass question when you need one fact, such as the total to pay. Do not ask the user to type the page out.

When a project is open, path is inside that project. In general chat, path is under uploads/. When full system control is on, a path that starts with / is allowed.
