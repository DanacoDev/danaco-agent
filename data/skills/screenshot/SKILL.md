---
name: screenshot
description: Takes a picture of a project page or a public page. args path or url, optional save, width, height.
version: 1.0.0
---

args path or url, optional save, width, height. Takes a picture of a page in this project or a public page. path is an html, htm, or php file, or a folder with an index page. url is a public http or https address. Saves a png under screenshots/ unless save is set. Cite that path alone on a line so the user sees the picture. Call read_image on it when you need to see what is wrong. Open a project before taking a screenshot.
